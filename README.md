# Fluent Welding Website

Static business website prepared for GitHub Pages and the custom domain `fluentwelding.com`.

## Publish on GitHub Pages
1. Create a GitHub repository (example: `fluent-welding-website`).
2. Upload all files in this folder to the repository root.
3. Open **Settings > Pages**.
4. Set the site to deploy from the `main` branch, root folder.
5. Under **Custom domain**, enter `fluentwelding.com`.
6. Configure DNS at the domain registrar following GitHub's current GitHub Pages custom-domain instructions.
7. Add `www.fluentwelding.com` as a CNAME to your GitHub Pages hostname if you want both root and www versions.
8. Enable **Enforce HTTPS** after DNS verification completes.

## Before launch
- Replace placeholder contact information.
- Connect the quote form to Google Forms, Formspree, Basin, or another submission endpoint.
- Add real project/product photography and logo assets.
- Confirm all product/service descriptions.
